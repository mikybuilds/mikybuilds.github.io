Perché Lanterna

Un buon modello in locale richiede una scheda video potente. Volevo che anche chi ha un PC normale potesse avere un assistente capace, senza pagare.

Lanterna nasce da ciò che ho imparato con MikyCore, il mio assistente personale, ma senza nessun dato personale: è un progetto pubblico con licenza MIT. Usa i piani gratuiti dei servizi cloud e passa ai modelli locali (Ollama) sui computer che ce la fanno.

Cosa sa fare

Un assistente generale, non solo una chat. Ogni cosa che tocca file o account chiede prima il tuo OK.

Modelli gratuiti, sempre uno disponibile

Groq, Gemini, OpenRouter, Cerebras, Mistral e GitHub Models, con le tue chiavi gratuite. Quando uno raggiunge il limite risponde il successivo, e la barra sotto il messaggio mostra quanto resta.

Anche in locale, con Ollama

Guarda la tua scheda video e consiglia i modelli adatti. Modalità Cloud, Locale o Auto: in Auto le domande difficili vanno al cloud e le altre restano sul tuo PC.

Ricorda e ti avvisa

Memoria, promemoria con notifica, ricerca sul web, meteo e calcolo delle date.

File e foto

Una cartella di lavoro per ogni chat. Legge subito; ogni modifica arriva come scheda con Conferma. Non cancella mai niente.

Google Drive e GitHub

Crea cartelle, carica file, fa push dei tuoi progetti: solo dopo Conferma e con il minimo dei permessi.

La stessa chat su ogni dispositivo

Accedi con Google: le chat restano in una cartella nascosta del tuo Drive, cifrate con AES-256 e la tua password. Le chiavi API non vengono sincronizzate.

Privata per costruzione

Le chiavi stanno nel portachiavi del sistema, niente telemetria, nessun account Lanterna. L'installer si aggiorna da solo e controlla l'impronta SHA-256.

Com'è fatta

La chat: le risposte arrivano in streaming e in alto vedi quale modello sta rispondendo.

Impostazioni: lingua, nome e modalità Cloud, Locale o Auto (le domande difficili vanno al cloud).

Primo avvio: Lanterna controlla la scheda video e consiglia i modelli locali. Niente si scarica finché non premi il pulsante.

Su Linux è un'app a schermo intero nel terminale, con il supporto del mouse.

Installa

Gratis, senza account. Windows con un installer, Linux dal terminale.

Windows 10 / 11

  1. Scarica Lanterna-Setup dall'ultima release.
  2. Avvialo: non servono diritti di amministratore.
  3. Se Windows avvisa «Editore sconosciuto», scegli Maggiori informazioni → Esegui comunque. L'installer non è firmato (la firma costa), ma lo costruisce GitHub Actions dal codice pubblico.

Scarica l'ultima versione

Linux

App a schermo intero nel terminale. Serve Python 3.10 o più recente.

sudo apt update && sudo apt install -y pipx git pipx ensurepath
pipx install git+https://github.com/mikybuilds/lanterna

Poi scrivi lanterna in un terminale. Per averlo anche nel menu delle app: lanterna desktop.

Sotto il cofano

Ogni release è costruita da GitHub Actions: test su Ubuntu e Windows, scansione dei segreti, installer e impronta SHA-256 per l'aggiornamento automatico.
